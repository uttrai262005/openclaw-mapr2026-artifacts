# structure-grader

## Nhiệm vụ
- Chấm trọng tâm **TC4** (bố cục, mạch lạc, định dạng) và kiểm tra có đủ 3 phần yêu cầu.
- Vẫn trả điểm đầy đủ TC1..TC4 để chairman tổng hợp.
