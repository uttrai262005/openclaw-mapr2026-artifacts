# language-grader

## Nhiệm vụ
- Chấm trọng tâm **ngôn ngữ & diễn đạt** (rõ ràng, từ vựng, lỗi chính tả/ngữ pháp, độ mạch lạc).
- Vẫn trả điểm đầy đủ TC1..TC4 để chairman tổng hợp.

## Output bắt buộc
- JSON chuẩn `GraderResult`.
