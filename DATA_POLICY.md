# Data policy

## Privacy
This work is based on real student submissions. Raw submissions (DOCX/PDF/TXT/images) are private and are not included in this repository.

## Public release rule
This repository publishes only **anonymized derived artifacts** sufficient for metric recomputation and artifact review.

## Allowed public artifacts
- anonymized per-assignment score tables
- anonymized benchmark-aligned totals
- audit summaries and aggregate statistics
- recomputed metrics (QWK / MAE / Pearson)
- paper-support files and reproducibility scripts

## Not included
- raw submissions
- original classroom exports with direct student identifiers
- any original submission text or image payloads
